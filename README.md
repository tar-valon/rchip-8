# rchip-8

## CHIP-8 emulator written in Rust

A simple Chip 8 emulator written in Rust. The goal of this project was to learn emulation development

---

## Usage

To run a rom using the emulator, simply run the following command
```
cargo run /path/to/rom
```

The keyset for the emulator is
```
1 2 3 4
q w e r
a s d f
z x c v
```

---

### Requirements

- Rust (latest stable)
- SDL2 (for graphics)
